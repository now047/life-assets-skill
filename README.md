# life-assets — ライフ資産スキル

金融資産に、健康・モノ・体験・学びの「充実度資産」を重ねて、一つの残高として見るための Agent Skill です。

お金の残高だけを見ていると、「お金を増やすこと」自体が目的になりがちです。このスキルは、お金以外の価値――運動の習慣、買って嬉しかったモノ、家族との思い出、読書や学び――も金額換算して台帳に記録し、金融資産と並べて眺められるようにします。目的は残高を貯めることではなく、お金と時間を「幸福への変換効率」が高いものへ振り向ける判断材料にすることです。

設計の考え方と理由は [references/design.md](references/design.md) にまとめてあります。共有したいのは実装そのものより、この設計のほうです。実装は各自のエージェント環境に合わせて作り替えてもらって構いません。

## 状態

- v0.1（試行中）。換算レートなどの数値はすべて暫定値で、運用しながら見直しています。
- 決めきれていない論点（総額に占める非金融資産の小ささ、終わり方と生活防衛ライン、換算レートの校正方法など）は、設計書の「6. 未決論点」に正直に書いてあります。

## インストール

Agent Skills 形式（SKILL.md）に対応したエージェントで使えます。

- skills CLI を使う場合：
  ```
  npx skills add now047/life-assets-skill
  ```
- 手動の場合：このリポジトリの中身を、エージェントのスキル置き場（例：`.agents/skills/life-assets/` や `.claude/skills/life-assets/`）にコピーしてください。

## セットアップ

1. データフォルダを用意し、`templates/params.json` を `params.json` としてコピーします。
2. `start_date` と金融資産の初期値を、自分の実績に書き換えます。
3. 台帳 `events.jsonl` は空から始めます（過去には遡りません）。
4. 記録は `scripts/add_event.py`、ダッシュボードの生成は `scripts/build.py` を使います。詳しい運用ルールは SKILL.md にあります。

必要なのは Python 3（標準ライブラリのみ）です。

## プライバシー

共有されるのはスキルとテンプレートだけです。台帳の実データ（自分の `params.json` や `events.jsonl`）は各自の手元で管理するもので、このリポジトリには含まれませんし、含めるべきでもありません。
